# «Граф» оқу зертханасы — 0.7 нұсқасы

Бұл — 11-сыныптың «Графтағы алгоритмдер» тарауына арналған оқу платформасы. Интерфейс пен 15 сабақтың материалдары орыс және қазақ тілдерінде қолжетімді. Платформаны өз компьютеріңізде іске қосуға болады; 0.7 нұсқасында жабық онлайн-пилотты тұрақты серверге орналастыруға арналған құралдар қосылды.

## 0.7: тұрақты серверге орналастыру

Linux VPS үшін Docker Compose конфигурациясы дайындалды: ол қолданбаны, HTTPS үшін Caddy серверін және SQLite дерекқорының резервтік көшірмесін жасайтын қызметті іске қосады. Node.js 24 контейнердің ішінде бар. Екі бөлек домен атауы қажет: біреуі платформаға, екіншісі браузердегі Python ортасына арналған.

Онлайн-нұсқада екі деңгейлі кіру бар: алдымен жабық демонстрацияның ортақ логині мен құпиясөзі, одан кейін платформаның жеке оқушы немесе мұғалім аккаунты. Демонстрация құпиясөзі GitHub-та сақталмайтын бөлек файлға жазылады.

Дерекқор тұрақты Docker томында сақталады. Резервтік көшірме қызмет іске қосылғанда және одан кейін әр 24 сағат сайын жасалады; әдепкіде соңғы 14 көшірме сақталады. Қолмен көшіру мен қайта іске қосу қосымша көшірме жасайтындықтан, бұл міндетті түрде 14 күндік тарих дегенді білдірмейді. Көшірмелерді серверден тыс қауіпсіз жерге де жүктеп алу керек.

Қалпына келтіру құралы деректерді жаңа файлға жазады және бұрынғы базаны алмастырмайды. Серверді іске қосу, жаңарту, көшірмені жүктеу және қалпына келтіру қадамдары орыс тіліндегі [DEPLOYMENT.md](DEPLOYMENT.md) нұсқаулығында берілген.

**Конфигурацияның дайын болуы сайттың жарияланғанын білдірмейді.** VPS, домендер мен құпиясөзді баптап, нақты HTTPS мекенжайында кіруді, Python тапсырмаларын және деректердің сақталуын тексеру қажет. Бұл кезең автор мен ғылыми жетекшіге арналған жабық пилот; мектеп оқушыларының нақты деректерімен жұмыс істеу үшін қосымша дайындық қажет.

Төмендегі жергілікті іске қосу жолы өзгермейді: `START.cmd` және Node.js 22.13 немесе одан жаңа нұсқа.

## 0.6 нұсқасында не өзгерді

Бөлім карточкалары, белгішелер және мәтіндер үлкейтілді. Келесі сабақ пен ілгерілеу курс бағдарламасының үстінде орналасқан. Графты басқару батырмалары бір панельге жиналды. Деректерді қалпына келтіру, тіл ауыстыру және Python редакторына қатысты қателер түзетілді. Қосымша мәлімет: TECH_REVIEW_V06.md.

## 0.5 нұсқасынан сақталған миссия

«Хабарламаны жеткіз» BFS миссиясы қосылды. Мәзірден «Миссиялар» бөлімін ашыңыз: кезекті өзіңіз басқарып, екі желідегі ең қысқа маршруттарды құрастырып, нәтижені түсіндіресіз. Қате әрекеттен кейін қайталап көруге және көмек алуға болады.

Алдымен кезектегі бірінші төбені таңдаңыз. Оның әлі ашылмаған көршілерін нөмірлерінің өсу ретімен қосып, «Барлық көршілер тексерілді» батырмасын басыңыз. Бүкіл кезекті қайта сұрыптамаңыз. Айналып өту аяқталғанда бастапқы төбеден мақсатқа дейін маршрут құрастырыңыз.

Нәтиже тек осы браузерде сақталады, мұғалім кабинетіне автоматты түрде жіберілмейді. Есепті JSON түрінде жүктеп алуға болады. Бұл жаттығу мектеп бағасы болып саналмайды. «Қайта өту» арқылы жаңа әрекетті бастауға болады.

## 0.4 нұсқасынан сақталған мүмкіндіктер

Курс картасында сабақтарды іздеу және оқуды жалғастыру карточкасы бар. 01–15 — курс ішіндегі сабақ реті, № 17–32 — оқу жоспарындағы нөмірлер. Алгоритмді басқару батырмалары графтың үстінде орналасқан. Негізгі ой мен өз бетімен орындау тапсырмасы бірден көрінеді.

Таңдалған жауаптар қойындылар арасында және бетті жаңартқанда осы құрылғыда сақталады. Түсінуді тексеру нәтижесі бүкіл дағдыны меңгергеніңізді білдірмейді: практикалық жұмысты мұғалім бөлек бағалайды. Код редакторынан шығу үшін Shift+Tab немесе Escape, одан кейін Tab басыңыз.

Толық аудит пен келесі қадамдар орыс тіліндегі [PRODUCT_AUDIT.md](PRODUCT_AUDIT.md) файлында берілген. Бұрынғы серверді тоқтатып, жаңа папкадағы START.cmd файлын іске қосыңыз. Дерекқорды көшіру алдында README.md нұсқаулығын оқыңыз.

## Іске қосу

1. ZIP мұрағатын толық ашыңыз.
2. `START.cmd` файлын іске қосыңыз. Node.js 22.13 немесе одан жаңа нұсқа қажет.
3. Браузерде **http://127.0.0.1:4318** мекенжайын ашыңыз.
4. Жоғарғы оң жақтағы тіл тізімінен **«Қазақша»** таңдаңыз.
5. Сервер терезесін ашық қалдырыңыз. Тоқтату үшін сол терезеде **Ctrl+C** басыңыз.

Тіл таңдауы осы браузерде сақталады. Тілді ауыстырғанда ағымдағы сабақ, алгоритм қадамы, бастапқы және мақсатты төбелер, 2D/3D таңдауы, белгіленген жауаптар және код сақталады. 3D камерасы бастапқы көрініске оралады. Python орындалып жатқан кезде тіл ауыстырылса, орындау тоқтатылады, код сақталып, хабарлама көрсетіледі.

## Алғашқы қадамдар

- «Неден бастау керек» бөлімінен оқу ретін және сөздікті қараңыз.
- 17–18-сабақтарда төбелерді, қабырғаларды және граф түрлерін зерттеңіз.
- 19-сабақта «Келесі қадам» батырмасын екі рет басыңыз: кезекте 4, 3, 5 болады.
- 23-сабақта рекурсия мен шақырулар стегін бақылаңыз.
- Python қойындысында мысалды ашып, редакторға жүктеп, тексеруді іске қосыңыз.

Python коды мен функция атаулары өзгермейді. Пайдаланушы жазған код, есім, сынып атауы және пікір автоматты түрде аударылмайды. Интерпретатор қателері мен бағдарламаның өзі шығарған мәтін бастапқы тілінде көрсетіледі. Бұрын сақталған тексеру есебі де бастапқы тілінде қалады.
