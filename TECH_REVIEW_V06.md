# Техническая проверка изменений для v0.6

Дата: 29 сентября 2026 года. Проверялись исходники `outputs/graph-classroom`.

## Вывод

Алгоритмическая основа и сохранение миссии прошли проверки. Найдены и исправлены реальные ошибки на границах сценариев: повреждённые данные браузера, повторное объяснение после завершения миссии и запоздавшие ответы сервера. Это делает прототип надёжнее для самостоятельного тестирования. Готовность к школьному развёртыванию и учебную эффективность эти проверки не подтверждают.

Итоговый общий запуск 29 сентября: **37/37 тестов пройдено**, без пропущенных. В том числе тест предельных пользовательских графов и регрессия локализации текста рядом с SVG.

Команда общего запуска: `node --test tests/*.test.mjs` из каталога проекта. API-тесты поднимают собственный сервер на портах 4390/4391 и используют временную SQLite-базу. Пользовательская `.local` база при этой проверке не изменялась.

## Найденные ошибки и исправления

- Миссия принимала массив в поле типа события через неявное преобразование JavaScript. Тип действия и этап теперь проверяются строго.
- После повторного неверного объяснения сохранялся старый признак успеха. Он сбрасывается при изменении ответа; запоздавшие события удалённой формы игнорируются.
- Некорректный JSON правильного синтаксиса мог сломать карту курса или редактирование ответа. Добавлены нормализаторы входных данных.
- Ответы API могли обновить экран после перехода, смены аккаунта или класса. Добавлены проверки контекста запроса.
- Загрузка сохранённого решения могла подменить редактор во время выполнения Python. Добавлены проверки запуска и конкретного экземпляра редактора.
- При отказе localStorage переход между экранами мог потерять текущую попытку. Добавлен запасной буфер в памяти вкладки; интерфейс продолжает сообщать, что постоянное сохранение не удалось.

Последние три пункта проверены по исходникам. Автоматического браузерного воспроизведения задержек сети, смены аккаунтов и отказа хранилища в этой технической проверке не было. Их следует отличать от тестов чистых функций выше.

## Что остаётся открытым

- Несколько вкладок одного аккаунта могут перезаписать локальную попытку друг друга. Между устройствами миссия не синхронизируется.
- Счётчики и ответы в локальном файле можно изменить вручную. Отчёт миссии — материал для обсуждения, а не доверенная школьная оценка. Счётчик ошибок объяснения хранится отдельно, без журнала для пересчёта.
- Нагрузку целого класса, слабые школьные компьютеры, работу экранным диктором, педагогическую пользу и качество казахского текста здесь не проверяли.
- Самопроверка Python выполняется на клиенте. Она не заменяет оценку учителем и не является защищённой системой экзамена.
- Перед школьным пилотом нужны отдельная подготовка размещения, управление ролями, восстановление доступа, резервное копирование и проверка работы с реальными учениками.

Визуальную проверку интерфейса и размеры экранов следует фиксировать отдельно: прохождение тестов JavaScript не доказывает удобство UI.

## Проверено в браузере для 0.6

- Карта курса: поиск по BFS и номеру занятия, сохранение поискового запроса при смене RU/KK, переход к занятию, отображение выполненной проверки.
- BFS: на втором шаге из старта 1 очередь 4, 3, 5; 2D/3D переключаются, ссылка на миссию остаётся одной. Стрелки клавиатуры переключают вкладки с переносом фокуса.
- 3D: при смене языка сохраняются шаг и фактический режим «Перемещение вершин»; это проверено по состоянию SVG, а не только выбранному пункту списка.
- Тренировка: правильные ответы дали 2 из 2. Python: загруженный учебный пример прошёл 8 из 8 проверок; Tab-редактирование сбросило старый результат. Escape, затем Tab вывели фокус из редактора.
- Миссия: преждевременное завершение объясняет ошибку; после правильного добавления соседей и перезагрузки восстановились очередь 2, 4 и одна ошибочная попытка.
- Размеры: карта и урок просмотрены при 1440 × 900; режим показа — при фактическом внутреннем размере 1366 × 720 (граф и легенда помещаются по высоте). Узкий режим — 390 px, доступная ширина 375 px; карта RU/KK и миссия KK без горизонтального переполнения. Физический проектор не проверялся.

Проверка браузером не охватывала полный повторный путь аккаунтов и искусственные задержки API. Границы доступа подтверждаются API-тестами, исправления гонок — пока анализом кода. Скриншоты релиза находятся рядом с ZIP: course-v0.6.png и lab-v0.6.png.
